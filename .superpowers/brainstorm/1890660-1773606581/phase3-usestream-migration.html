GET /api/info
  → {"version": "1.0", "graphs": ["emma-react"]}

GET /api/threads
  → Query checkpointer for thread list (by tenant_id)
  → [{"thread_id": "...", "created_at": "...", "metadata": {...}}]

GET /api/threads/{thread_id}/state
  → Get current graph state from checkpointer
  → {"values": {"messages": [...], ...}, "checkpoint": {...}}

GET /api/threads/{thread_id}/history
  → Checkpoint history for branch switching
  → [{"checkpoint": {...}, "parent_checkpoint": {...}, ...}]

POST /api/threads/{thread_id}/runs
  ← {"input": {"messages": [...]}, "stream_mode": ["values"]}
  → SSE stream (LangGraph protocol format)

POST /api/threads/{thread_id}/runs (with command)
  ← {"command": {"resume": {"decisions": [...]}}}
  → Resume interrupted graph via Command(resume=...)

Verified Generation as Subgraph

Architecture: Verified Gen → LangGraph Subgraph
# Current: Separate SSE endpoint (/emma/verified/stream)
# Target: Subgraph within main ReAct graph

Main Graph (emma-react):
  classify → rewrite → memory_recall → react_loop ⟲ → synthesize
                                  ↓ (tool: verified_generate)
                            Verified Subgraph:
                              initialize → extract → evaluate ⟲ → synthesize
                                              ↑ interrupt() for HITL review

# Benefits:
• One SSE stream — all events (chat + verified) flow through useStream
• Checkpointed — verified state persists across reconnects
• HITL native — review interrupt uses same protocol as email confirm
• streamSubgraphs: true — frontend receives subgraph events for panel updates

# Frontend receives subgraph updates as:
event: updates
data: {"verified_subgraph:evaluate": {
  "claims": [...], "current_claim_index": 3, "total_claims": 5
}}

Migration Strategy (Incremental)

1
Spike test: useStream + adapter
Minimal /api/info + /api/threads/{id}/runs endpoint. Validate useStream connects and receives messages. ~2 days.
2
Chat migration: EmmaChat → useStream
Replace manual SSE with useStream hook. Add interrupt rendering. Old /emma/stream stays as fallback. ~1 week.
3
Verified Gen subgraph
Convert stop-and-go to LangGraph subgraph. Events flow through useStream to artifacts panel. ~1 week.
4
Branch switching + regenerate + thread history
Wire up useStream features to UI components. History endpoint + checkpoint browsing. ~3 days.
5
Cleanup: remove old SSE
Delete /emma/stream, /emma/query, legacy emma.py SSE. Single protocol. ~2 days.
