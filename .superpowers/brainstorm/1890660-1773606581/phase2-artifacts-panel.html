Key Behaviors

Auto-open
Panel opens automatically when Verified Gen or Forge starts. No manual button needed.
Non-blocking
Chat continues while artifacts process. User can ask questions while waiting for verification.
Tab persistence
Multiple artifacts coexist as tabs. Completed artifacts stay until user closes them.
Collapse to pill
User can collapse panel to a floating pill showing artifact count + status. Click to reopen.
