Phase 1: HITL Protocol — Approve / Edit / Reject

Generalised interrupt handling for any tool call that needs human review

Backend Protocol: interrupt() → SSE event

LangGraph Node (Python) — e.g. react_loop
from langgraph.types import interrupt

# When a tool needs human review:
decision = interrupt({
  "type": "hitl_review",
  "action_request": {
    "name": "send_email",
    "args": {
      "to": "user@test.com",
      "subject": "Contrato de arrendamiento",
      "body": "Adjunto el contrato...",
    },
    "description": "Enviar email con contrato adjunto",
  },
  "review_config": {
    "allowed_decisions": ["approve", "edit", "reject"],
    "editable_fields": ["to", "subject", "body"],
  },
})

# After resume:
if decision["type"] == "approve":
  await registry.execute("send_email", tc_args, context)
elif decision["type"] == "edit":
  await registry.execute("send_email", decision["edited_args"], context)
elif decision["type"] == "reject":
  feedback = decision.get("message", "")
  # Agent receives feedback and adjusts

SSE Event Format

SSE: event: hitl_review
// New SSE event emitted when interrupt() fires
event: hitl_review
data: {
  "interrupt_id": "int_abc123",
  "action_request": {
    "name": "send_email",
    "args": { "to": "...", "subject": "...", "body": "..." },
    "description": "Enviar email con contrato adjunto"
  },
  "review_config": {
    "allowed_decisions": ["approve", "edit", "reject"],
    "editable_fields": ["to", "subject", "body"]
  }
}

Tools que usan HITL Review

Decisions: approve, edit, reject

Decisions: approve, edit, reject

Read-only args (no edit)
Decisions: approve, reject
